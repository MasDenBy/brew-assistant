# Munich Malt

**Type:** Ingredient (Malt)
**Source:** Generated for Phase 1 prototype

## Overview
Munich malt is a rich, kilned German base or specialty malt with a deep bready, malty, slightly toasty character. It forms the base of Märzens, Bocks, and Oktoberfest beers; smaller amounts add malt complexity to amber ales, porters, and lagers.

## Key Specs
- Color: 6–10 °L (light) / 9–20 °L (dark versions)
- Diastatic power: moderate-high (light Munich is self-converting)
- Typical usage: 100% base for Märzen/Bock; 5–20% as specialty in ales
- Flavor: bready, toasty, malty, slightly caramel

## Common Substitutions
- **Victory / Biscuit malt** — similar toasty character; use up to ~15% for the same direction
- **Helles/Munich (light) vs dark** — swap between light and dark Munich for intensity
- **Pilsner + melanoidin malt** — approximates Munich's complexity (use melanoidin sparingly, 2–5%)
- **CaraMunich** — adds more caramel sweetness; use when a rounder, sweeter profile is wanted
