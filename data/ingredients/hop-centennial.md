# Centennial Hops

**Type:** Ingredient (Hop)
**Source:** Generated for Phase 1 prototype

## Overview
Centennial (sometimes called "Super Cascade") is a classic American dual-purpose hop released in 1990. It has a floral-citrus profile very similar to Cascade but with higher alpha acids, making it suitable for both bittering and aroma.

## Key Specs
- Alpha acid: 9.5–11.5%
- Beta acid: 3.5–4.5%
- Common uses: bittering, flavor, aroma — a true dual-purpose hop
- Flavor/aroma: floral, citrus, grapefruit, slight spice
- Origin: USA

## Substitutions
- **Cascade** — the obvious swap (lower alpha; adjust bittering charge upward)
- **Columbus/Zeus** — similar alpha but more dank/herbal; use when citrus is secondary
- **Amarillo** — citrus-floral, slightly more orange
- **Chinook** — higher alpha with more pine; a workable bittering substitute
