# Hefeweizen Yeast (Wyeast 3068 / WLP300)

**Type:** Ingredient (Yeast)
**Source:** Generated for Phase 1 prototype

## Overview
German wheat beer yeast is famous for producing the signature Hefeweizen esters: banana (isoamyl acetate) and clove (4-vinyl guaiacol, a phenol). The same strain makes Weizenbocks and Dunkelweizens. Fermentation temperature controls the banana/clove balance.

## Key Specs
- Attenuation: 73–80%
- Flocculation: low (beer stays cloudy — correct for the style)
- Alcohol tolerance: 10–11% (Wyeast 3068 / WLP300)
- Recommended temperature: 17–22 °C for balanced esters
- Flavor contribution: banana, clove, bubblegum; phenolic, fruity

## Common Substitutions
- **WLP300 (Weihenstephan Weizen)** — liquid equivalent of 3068
- **Fermentis WB-06 (dry)** — produces clove-forward character with less banana; the best dry substitute
- **Fermentis BE-134 (Saison)** — not a wheaten yeast, but delivers spicy/phenolic character if a Saison-leaning wheat is acceptable
- **Wyeast 3333 (German Wheat)** — similar profile, slightly more restrained banana
